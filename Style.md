# 1. Brand Direction

## 2.1 Brand Name

**NESTORA**

### Brand category

Modern furniture and home living.

### Core positioning

> Modern furniture for modern living.

NESTORA should feel like a **real premium furniture brand**, not a generic template or demonstration e-commerce website.

# 3. Visual Personality

NESTORA's visual personality should communicate:

- Modern
- Warm
- Sophisticated
- Calm
- Minimal
- Premium
- Comfortable
- Trustworthy
- Contemporary
- Human

The interface should feel carefully designed rather than technically assembled.

# 4. The Desired Emotional Experience

When a visitor enters NESTORA, the visual experience should communicate:

> "This is a beautiful, trustworthy furniture store where I can imagine these products in my home."

The design should encourage:

**Explore → Imagine → Trust → Choose → Purchase**

The interface should not feel:

- Aggressive
- Overly corporate
- Cold
- Futuristic for the sake of being futuristic
- Visually noisy
- Cheap
- Overly playful
- Like a generic SaaS dashboard

# 5. Design Philosophy

NESTORA should follow:

## Editorial Minimalism

Large imagery, controlled typography, generous whitespace and deliberate composition.

## Product First

Furniture is the visual hero.

UI elements should support the products rather than compete with them.

## Warm Minimalism

The design should be minimal without feeling sterile.

Use warmth through:

- Natural tones
- Furniture photography
- Soft backgrounds
- Subtle borders
- Comfortable spacing
- Human copy

## Quiet Premium

Premium should come from:

- Typography
- Spacing
- Photography
- Composition
- Consistency
- Interaction quality

Not from excessive gradients, glowing effects, animations or visual decoration.

# 6. Overall Visual Rule

When choosing between:

**More decoration**

and

**More whitespace**

prefer whitespace.

When choosing between:

**More UI elements**

and

**Clearer hierarchy**

prefer clearer hierarchy.

When choosing between:

**Complex animation**

and

**Subtle movement**

prefer subtle movement.

When choosing between:

**More colours**

and

**A controlled palette**

prefer a controlled palette.

# 7. Colour System

The colour palette should be inspired by modern interiors and natural materials.

The primary palette should remain neutral and warm.

## 7.1 Base Colours

Background:

Soft White

Deep Charcoal

Secondary Text:

Warm Gray

Soft Warm Gray

Muted Earth Tone

Avoid pure black as the dominant text colour.

Prefer a deep charcoal.

Example conceptual palette:

Border \#E5E1D8

These values are starting tokens, not a requirement to use these exact hexadecimal values if the final Figma design establishes a refined palette

# 8. Colour Usage Rules

The interface should generally use:

70–80% Neutral Backgrounds

15–20% Text / Dark Elements

5–10% Accent Colour

Do not use the accent colour everywhere.

Accent colours should draw attention to:

- Primary CTAs
- Important interactive states
- Selected states
- Small visual highlights

# 9. Dark Sections

Dark sections may be used selectively.

Examples:

- Promotional section
- Footer
- Brand statement
- Newsletter CTA

Dark sections should use:

- Deep charcoal
- Warm off-white text
- Muted secondary text

Do not turn the entire site into a dark interface.

# 10. Semantic Colours

Semantic colours should be muted rather than excessively saturated.

## Success

Use a restrained green.

## Warning

Use a warm amber.

## Error

Use a restrained red.

## Information

Use a muted blue/neutral tone.

These colours should primarily communicate state rather than become decorative elements.

Errors should be:

- Specific
- Close to the relevant field
- Easy to understand

# 64. Toasts and Notifications

Use toast notifications sparingly.

Good use cases:

Added to wishlist

Removed from wishlist

Added to cart

Cart updated

Do not use toasts for critical information that the user must retain.

# 65. Modals

Use modals sparingly.

Avoid turning simple interactions into modal workflows.

A modal may be used for:

- Confirmation
- Important contextual information
- Mobile-specific interactions

Do not use modals for ordinary product browsing.

# 66. Icons

Use one consistent icon family.

Icons should be:

- Simple
- Clean
- Consistent in stroke weight
- Visually balanced

Do not mix unrelated icon styles.

# 67. Icon Rules

Icons should support meaning.

Do not replace important text with icons alone unless the meaning is universally recognizable.

Examples:

Good:

♡ Wishlist

🛒 Cart

Better accessibility:

button aria-label="Add Cloud Sofa to wishlist"

# 68. Animation Philosophy

Animation should communicate:

- State change
- Continuity
- Feedback
- Hierarchy

Animation should not exist merely because animation is possible.

# 69. Animation Timing

Recommended:

Micro interaction:

150–200ms

Standard:

200–400ms

Large transition:

400–700ms

Avoid slow animations that make shopping feel sluggish.

# 70. Page Transitions

Page transitions should be subtle.

Avoid:

- Large wipes
- Excessive zooming
- Complex 3D transitions
- Long loading animations

The customer should feel that the interface is fast.

# 71. Scroll Animations

Sections may reveal subtly as the user scrolls.

Possible:

opacity

translateY

small scale

Avoid excessive parallax.

Do not animate every element independently.

# 72. Reduced Motion

Respect:

prefers-reduced-motion

Users who request reduced motion should not receive unnecessary animations.

# 81. Desktop Layout

Desktop should make good use of whitespace.

Do not stretch text across the entire viewport.

Content should remain contained within the established max-width.

Large furniture imagery may extend wider than standard text content when visually appropriate.

# 82. Tablet Layout

Tablet should act as a deliberate intermediate layout.

Do not simply inherit desktop grid dimensions.

Adjust:

- Product columns
- Navigation
- Section spacing

- Image sizes

# 83. Accessibility

Visual design must support accessibility.

Minimum requirements:

- Keyboard-accessible controls
- Visible focus states
- Semantic headings
- Form labels
- Alt text
- Adequate contrast
- Accessible icon buttons
- Touch-friendly controls

# 84. Focus States

Do not remove browser focus indicators without replacing them.

Focus states should be visually consistent with the brand.

Example:

subtle outline

\+

accent or dark border

# 85. Touch Targets

Interactive elements should generally provide sufficiently large touch targets.

Particularly:

- Wishlist buttons
- Cart controls
- Quantity controls
- Navigation controls
- Form controls

Small decorative icons should not become difficult-to-use controls.

# 86. Content Density

NESTORA should feel spacious.

Avoid filling every section with:

- Text
- Cards
- Icons
- Buttons
- Decorative shapes

Whitespace is an intentional part of the design.

# 87. Visual Hierarchy

# 88. Design Consistency

The same design language must be reused across:

- Homepage
- Shop
- Product pages
- Cart
- Wishlist
- Checkout
- Account
- Orders

Do not redesign buttons, cards, inputs or typography on individual pages without a strong reason.

# 89. Avoid Generic E-commerce UI

NESTORA should not look like:

Generic Bootstrap store

or:

Generic Tailwind template

Avoid:

- Excessive rounded cards
- Random gradients
- Generic hero sections
- Huge text with no composition
- Excessive glassmorphism
- Excessive shadows
- Random decorative blobs
- Overuse of icons
- Dashboard-like layouts
- Overuse of badges

# 90. Avoid Excessive SaaS Aesthetics

NESTORA is an e-commerce furniture brand, not an AI SaaS product.

Avoid:

- Neon gradients
- Glowing cards
- Cybersecurity-style interfaces
- Excessive dark mode
- Futuristic grids
- Terminal-inspired elements
- Abstract tech illustrations

The product category should determine the visual language.

# 91. Premium Quality Checklist

Before considering a page visually complete, check:

### Typography

- Is the hierarchy obvious?
- Are font sizes intentional?
- Is line-height comfortable?

### Spacing

- Is there enough breathing room?
- Are sections consistently spaced?
- Are elements aligned?

### Colour

- Is the palette controlled?
- Is the accent colour being overused?
- Are secondary elements sufficiently muted?

### Imagery

- Are images high quality?
- Are aspect ratios consistent?
- Do images feel like they belong to the same brand?

### Components

- Are buttons consistent?
- Are cards consistent?
- Are controls aligned?

### Responsive

- Does the design work at mobile widths?
- Does content remain readable?
- Are touch targets large enough?

### Interaction

- Do hover states exist?
- Do focus states exist?
- Do loading states exist?
- Do disabled states exist?

# 92. Visual Quality Bar

Premium furniture showroom

Student project

# 93. Design Decision Priority

When making visual decisions, prioritize:

1\. Product clarity

2\. Usability

3\. Visual hierarchy

4\. Brand consistency

5\. Accessibility

6\. Responsiveness

7\. Subtle interaction

8\. Decorative detail

Decorative detail should never compromise the first six.

# 94. Final Style Principle

NESTORA should feel:

> **Warm enough to feel like home.  
> Refined enough to feel premium.  
> Simple enough to feel effortless.**

Every visual decision should support that experience.

The design should make customers want to:

**browse → imagine the furniture in their space → trust the store → buy.**
