# 2. Core Taste Statement

NESTORA should feel like a **beautiful modern furniture brand that happens to have an excellent e-commerce website**.

It should not feel like:

> "an e-commerce website selling furniture."

That distinction is important.

The furniture brand comes first.

The technology exists to support the brand.

# 3. Design Personality

NESTORA should be:

- Refined
- Warm
- Calm
- Intentional
- Contemporary
- Confident
- Elegant
- Human
- Comfortable
- Understated

NESTORA should not be:

- Loud
- Cheap-looking
- Over-designed
- Corporate
- Childish
- Futuristic
- Cold
- Technically flashy
- Visually chaotic

# 4. The Central Design Tension

NESTORA should balance:

Minimal

\+

Warm

Premium

\+

Approachable

Editorial

\+

Practical

Modern

\+

Timeless

Beautiful

\+

Usable

Never allow one side to completely overpower the other.

For example:

### Too minimal

The site becomes cold and empty.

### Too warm

The site becomes rustic or overly traditional.

### Too premium

The site becomes intimidating.

### Too practical

The site becomes generic.

### Too editorial

The site becomes difficult to shop.

The goal is balance.

# 5. The First Impression Test

When someone sees the homepage for the first time, the desired reaction is:

> "This looks like a furniture brand I would actually shop from."

Not:

> "This looks like an AI-generated website."

Not:

> "This looks like a developer portfolio project."

Not:

> "This looks like a Tailwind template."

Not:

> "This looks like a Shopify theme."

The implementation should disappear behind the experience.

# 6. Brand Before Technology

Do not allow the technology stack to dictate the visual identity.

The fact that the application uses:

- Next.js
- React
- Tailwind
- Supabase
- AI coding agents

should have **zero influence** on the visual language.

NESTORA is a furniture brand.

Design decisions should come from:

- Furniture
- Interiors
- Architecture
- Materials
- Lifestyle
- Comfort
- Contemporary retail

# 7. Product Is the Hero

The furniture should receive more visual attention than the interface.

When deciding between:

Making the UI more visually impressive

and:

Making the product imagery more compelling

prefer the product.

The interface should frame the product.

It should not compete with it.

# 8. Photography Over Decoration

When a section needs visual interest, prefer:

Strong photography

over:

Decorative shapes

Furniture is inherently visual.

Use that advantage.

Avoid filling empty space with random:

- blobs
- circles
- gradients
- abstract illustrations
- floating shapes

unless they have a clear brand purpose.

# 9. Whitespace Is a Feature

Whitespace should never automatically be treated as wasted space.

A large amount of empty space can communicate:

- Confidence
- Premium positioning
- Calm
- Editorial sophistication

If a section feels slightly too spacious but still communicates clearly, that may be preferable to filling it with unnecessary content.

# 10. Don't Fill Space Just Because You Can

AI-generated interfaces often attempt to fill every empty area.

Do not do this.

If a section works with:

Heading

\+

Image

\+

CTA

do not add:

Extra icons

\+

Decorative cards

\+

Statistics

\+

Floating badges

\+

Random illustration

just to make it "look complete."

# 11. Restraint Is a Design Skill

A good design decision is sometimes:

> "We don't need this."

The agent should actively question whether an element contributes to:

- Understanding
- Navigation
- Trust
- Shopping
- Brand identity
- Conversion

If it contributes to none of these, remove it.

# 12. Premium Does Not Mean Complicated

A premium interface does not require:

- 3D effects
- Complex animations
- Glassmorphism
- Gradients
- Floating cards
- Video backgrounds
- Excessive motion

Premium can come from:

Good typography

\+

Excellent photography

\+

Spacing

\+

Consistency

\+

Detail

\+

Restraint

# 13. Avoid "AI Design"

The project must actively avoid the visual patterns commonly produced by generic AI-generated websites.

Avoid automatically reaching for:

- Purple-blue gradients
- Giant gradient text
- Glass cards
- Floating blobs
- Excessive rounded rectangles
- Random geometric decorations
- Excessive emoji
- Huge icons
- Generic "modern" illustrations
- Excessive animations
- Repetitive card grids
- Fake statistics

The fact that an element looks modern does not mean it belongs in NESTORA.

# 14. Avoid "Dribbblification"

Do not optimize the design merely to make screenshots look impressive.

A beautiful screenshot is not enough.

The interface must work as an actual store.

Prioritize:

Real usability

\>

Visual novelty

The customer should be able to find, evaluate and purchase products easily.

# 15. Avoid "Template Smell"

If a design could be copied and used unchanged for:

- A SaaS startup
- A crypto website
- A fashion store
- A law firm
- A productivity app

then it is probably not specific enough to NESTORA.

The design should contain enough furniture/home/lifestyle character to feel purpose-built.

# 16. Furniture Should Influence Composition

Use visual inspiration from:

- Interior design
- Architecture
- Furniture catalogues
- Luxury retail
- Home magazines
- Contemporary galleries
- Boutique furniture stores

The composition should sometimes feel editorial rather than purely transactional.

# 17. Editorial Influence

NESTORA can borrow from editorial design.

This can appear through:

- Strong typography
- Asymmetrical compositions
- Large photography
- Generous margins
- Interesting image crops
- Short, confident copy
- Intentional whitespace

But editorial design must not compromise shopping usability.

# 18. Asymmetry Is Allowed

Not every section needs to be:

Image \| Text

Image \| Text

Image \| Text

Controlled asymmetry can create visual interest.

Examples:

Large image

\+

Small text block

or

Text

\+

Large image

\+

Small supporting image

However, asymmetry must still feel balanced.

# 19. Grids Should Feel Intentional

Product grids are useful.

But not every section should become a grid.

Use grids for:

- Products
- Categories
- Benefits
- Structured information

Use editorial compositions for:

- Hero
- Promotional storytelling
- Brand statements
- Campaign sections

# 20. Copywriting Taste

NESTORA copy should be:

- Short
- Confident
- Warm
- Human
- Specific
- Calm

Avoid exaggerated marketing language.

# 21. Avoid Generic Marketing Copy

Avoid phrases such as:

> "Elevate your lifestyle to the next level."
>
> "Transform your space with our revolutionary furniture solutions."
>
> "Experience unparalleled excellence."

These sound generic.

Prefer:

> "Furniture made for slow mornings, long dinners and everyday living."

The copy should sound like a brand speaking to a person.

# 22. Avoid Excessive Sales Pressure

NESTORA should not constantly shout:

- BUY NOW
- LIMITED OFFER
- DON'T MISS OUT
- ACT NOW
- BEST DEAL
- HURRY

Furniture is a considered purchase.

The experience should allow the customer to explore and imagine.

# 23. CTAs Should Be Confident

Use clear action-oriented CTAs.

Good:

Shop Sofas

Explore the Collection

View Details

Add to Cart

View Order

Avoid unnecessarily aggressive CTAs.

# 24. Product Names Should Feel Real

Product naming should sound like an actual furniture catalogue.

Good examples:

Cloud Sofa

Luna Accent Chair

Oakline Dining Table

Milo Bed Frame

Arden Side Table

Avoid:

Ultra Premium Luxury Sofa 3000

Modern AI Smart Furniture Pro

Best Sofa Ever

# 25. Product Descriptions

Descriptions should help customers understand the product.

Prioritize:

- Material
- Form
- Comfort
- Dimensions
- Intended use
- Finish
- Style

Avoid filling descriptions with empty adjectives.

# 26. Trust Should Be Earned

Do not fabricate:

- Customer reviews
- Sales numbers
- Awards
- Years in business
- Customer counts
- Delivery claims
- Certifications

If NESTORA does not actually have the information, do not invent it merely to make the site look established.

# 27. No Fake Social Proof

Do not create fake:

> "10,000+ happy customers"

or:

> "Rated 4.9/5 by 2,000 customers"

unless real data exists.

Trust should come from:

- Clear product information
- Professional presentation
- Transparent ordering
- Reliable communication
- Good UX

# 28. No Fake Urgency

Do not invent:

> "Only 2 left!"

unless the actual database stock is 2.

Do not use fake countdown timers.

Do not create artificial scarcity.

# 29. Real Data Should Drive UI

If the interface displays:

- Stock
- Price
- Order status
- Product availability
- Delivery information

it should come from actual application data.

Visual design must not manufacture business facts.

# 30. Product Cards Should Breathe

Product cards should not contain too much information.

The preferred hierarchy is:

Image

↓

Product name

↓

Short category/context

↓

Price

Additional information should appear only when useful.

# 31. Don't Over-Badge Products

Avoid placing:

NEW

SALE

BESTSELLER

TRENDING

POPULAR

LIMITED

FEATURED

on the same product.

A product should not look like it is covered in stickers.

Use the single most relevant badge.

# 32. Wishlist Should Feel Natural

Wishlist functionality should feel like a natural part of shopping rather than a separate application feature.

The heart icon should be:

- Easy to discover
- Easy to use
- Visually subtle
- Clearly active when selected

# 33. Cart Should Feel Lightweight

Adding something to the cart should not interrupt browsing unnecessarily.

Prefer:

Add to Cart

↓

Small confirmation

rather than forcing the user to leave the product page immediately.

# 34. Checkout Should Feel Calm

Checkout is not the place for visual experimentation.

Reduce distractions.

The customer should feel:

> "My order is clear and I'm ready to submit it."

Avoid unnecessary animations and promotional content during checkout.

# 35. Account Pages Should Be Simpler

The account and orders experience does not need the same editorial treatment as the homepage.

Use:

- Clear hierarchy
- Efficient spacing
- Strong readability
- Familiar patterns

The homepage sells the brand.

The account area serves the customer.

# 36. Consistency Beats Novelty

If a component already works well, do not redesign it simply to make a page feel different.

Consistency creates:

- Trust
- Familiarity
- Professionalism

# 37. Don't Reinvent Standard Interactions

Customers already understand:

- Shopping carts
- Wishlist hearts
- Search
- Quantity controls
- Checkout
- Order lists

Use familiar interaction patterns.

Innovation should happen where it genuinely improves the experience.

# 38. Motion Should Feel Physical

When animation is used, imagine the physical world.

Furniture is:

- Solid
- Heavy
- Stable
- Tactile

Therefore interactions should feel:

- Smooth
- Controlled
- Deliberate

Avoid bouncy or cartoon-like animations.

# 39. No Excessive Bouncing

Avoid:

bounce

elastic

rubber-band

exaggerated spring

as the default interaction style.

Use subtle easing.

# 40. Hover Effects Should Be Quiet

Good hover:

Image gently scales

Button subtly darkens

Border becomes slightly stronger

Bad hover:

Card jumps

Image spins

Text moves dramatically

Shadow explodes

# 41. Mobile Comes First in Judgment

Even when designing desktop-first compositions, always ask:

> "Does this still make sense on a phone?"

If an interaction only looks good on desktop but becomes awkward on mobile, redesign it.

# 42. Don't Hide Important Actions on Mobile

The following should remain easy to access:

- Search
- Cart
- Wishlist
- Add to Cart
- Checkout
- Order information

Do not prioritize decorative content over functional actions.

# 43. Accessibility Is Part of Taste

Accessible design should not be treated as a technical afterthought.

Good taste includes:

- Readable text
- Clear focus states
- Good contrast
- Comfortable controls
- Understandable labels
- Keyboard support

An interface that looks beautiful but is frustrating to use is not considered successful.

# 44. Nigerian Context Without Stereotyping

NESTORA is intended for the Nigerian market.

The design should feel appropriate for Nigerian customers without relying on stereotypical visual cues.

Do not automatically add:

- Nigerian flags
- Green-white-green colour schemes
- Afrocentric patterns
- Generic African illustrations

unless the brand strategy specifically calls for them.

NESTORA can feel Nigerian through:

- Currency
- Delivery context
- Customer language
- Local availability
- Business information
- Practical UX decisions

without needing visual clichés.

# 45. Currency Presentation

Use Nigerian Naira consistently.

Preferred:

₦150,000

Avoid mixing:

NGN 150,000

N150,000

150K

randomly throughout the interface.

# 46. Tone of the Interface

Interface messages should sound like a helpful brand.

Prefer:

> "Your cart is empty."

over:

> "Oops! Looks like you haven't added anything yet! 😍"

Prefer:

> "Your order has been placed."

over:

> "Yay! Your order is on its way to becoming amazing! 🎉"

The brand is warm, but not childish.

# 47. Emoji Usage

Avoid emojis in core brand/UI copy unless deliberately introduced by the final brand direction.

NESTORA should communicate warmth through:

- Typography
- Photography
- Copy
- Colour
- Layout

not emoji decoration.

# 48. Icons Should Not Become Decoration

Every icon should have a reason.

Do not add icons simply because a card "looks empty."

Icons should clarify or support meaning.

# 49. Empty States Should Feel Human

Empty states should be useful, not overly theatrical.

Example:

> Your wishlist is empty.

Then:

> Save pieces you love and come back to them later.

CTA:

> Explore Furniture

This is enough.

# 50. Error States Should Be Calm

Errors should not make the interface feel broken or alarming.

Use:

Clear explanation

\+

Useful next step

Avoid giant red error screens for ordinary problems.

# 51. Loading States Should Feel Designed

Skeletons should match the actual content layout.

Do not use:

Generic spinning loader

for every page.

Where practical, use skeleton structures that resemble the content being loaded.

# 52. Avoid Excessive Skeletons

Not every tiny component needs a skeleton.

Use loading UI where the user would otherwise perceive a meaningful delay.

# 53. Design With Real Content

Do not design around:

Lorem ipsum

for too long.

Real product names and realistic descriptions should be used during design and development.

Text length affects layout.

# 54. Avoid Perfectly Uniform Content

Real products will have different:

- Names
- Descriptions
- Images
- Prices
- Variants

The interface should handle this gracefully.

Do not rely on every product having identical text lengths.

# 55. Don't Let Cards Break Because of Content

Product cards should remain visually aligned even when product names differ.

Use controlled text wrapping or line clamping where appropriate.

Do not aggressively truncate important information.

# 56. Design for Real Product Photography

The design should tolerate:

- Portrait images
- Landscape images
- Square images
- Lifestyle photography
- Product-only photography

The system should maintain a coherent presentation.

# 57. Image Quality Is Non-Negotiable

A sophisticated UI with poor product imagery will still feel cheap.

If resources are limited, prioritize:

Good product photography

\>

Complex UI effects

# 58. Don't Overuse Full-Bleed Images

Full-screen imagery can be powerful.

It can also become repetitive.

Use full-bleed imagery strategically:

- Hero
- Major campaign section
- Brand statement

Product grids should generally maintain a more structured composition.

# 59. Use Contrast Intentionally

A page can move between:

Light

↓

Dark

↓

Light

to create rhythm.

For example:

Hero — Light

Categories — Light

Best Sellers — Light

Promotion — Dark

Products — Light

Trust — Neutral

Why Shop — Warm

Newsletter — Dark

Footer — Dark

The exact implementation can change, but visual rhythm should exist.

# 60. Section Rhythm

A long homepage should not feel like one endless white canvas.

Create rhythm through:

- Background changes
- Image scale
- Typography
- Section spacing
- Content density
- Occasional dark sections

But maintain overall consistency.

# 61. Promotional Section Taste

The promotional section should feel like a campaign/editorial moment.

It should not resemble a flashing sale banner.

Preferred:

Strong image

\+

Short statement

\+

Clear CTA

Avoid:

SALE SALE SALE!!!

50% OFF!!!

BUY NOW!!!

COUNTDOWN!!!

# 62. Trust Stripe Taste

The trust stripe should be understated.

It should reassure without screaming:

> "TRUST US!"

Use concise statements and restrained iconography.

# 63. Footer Taste

The footer should feel like a natural conclusion to the site.

It should not become a dumping ground for every possible link.

Keep information organized.

# 64. Search Experience

Search should feel simple and useful.

The customer should be able to quickly search:

> sofa

and see relevant furniture.

Avoid turning search into an overly complicated filter system in V1.

# 65. Filtering Experience

Filters should help customers narrow products.

They should not overwhelm them.

Prioritize useful filters such as:

- Category
- Price
- Availability
- Sorting

Additional filters can be introduced when the product catalogue actually requires them.

# 66. Don't Build Features for the Sake of Completeness

The fact that Shopify has a feature does not mean NESTORA needs it.

Always ask:

> Does this help the customer shop?

If the answer is no, it does not belong in V1.

# 67. Don't Confuse Complexity With Quality

A more complicated interface is not automatically a better interface.

Prefer:

Simple + polished

over:

Complex + impressive-looking

# 68. Design Hierarchy of Importance

When visual attention is limited, prioritize:

1\. Product

2\. Primary action

3\. Product information

4\. Navigation

5\. Trust

6\. Secondary information

7\. Decoration

# 69. What to Do When Unsure

When a design decision is not specified, the agent should ask:

### Question 1

Does this improve the customer's ability to shop?

### Question 2

Does this strengthen NESTORA's furniture-brand identity?

### Question 3

Does this make the interface clearer?

### Question 4

Does this introduce unnecessary visual noise?

### Question 5

Would this still look appropriate if the site were printed as a furniture catalogue?

If the answer to the first three is no, do not add the element.

# 70. Decision Rule

When two design options are both technically valid:

Choose the option that is:

More intentional

\+

More restrained

\+

More useful

\+

More brand-specific

rather than the option that is simply more visually complicated.

# 71. When the Agent Should NOT Improvise

The agent should not independently change:

- Brand colours
- Typography system
- Major layout structure
- Homepage section order
- Navigation architecture
- Product card structure
- Checkout structure
- Core interaction patterns

if those decisions are already defined by Style.md, the Figma design, or the PRD.

# 72. Figma Has Priority for Visual Implementation

When an approved Figma design exists for a component or page:

Approved Figma design

↓

Style.md

↓

Taste.md

↓

Agent judgment

The agent should implement the approved design rather than redesigning it.

If the implementation encounters a technical constraint, preserve the design intent while adapting the implementation.

# 73. Figma Does Not Override Product Requirements

If the Figma design conflicts with a functional requirement in PRD.md, the agent should not silently remove the required functionality.

Example:

If the PRD requires:

> Customers must be able to view previous orders.

but a design mockup does not show an obvious Orders entry point, the functionality must still exist.

The conflict should be identified and resolved deliberately.

# 74. Taste Over Trend

Do not add a design trend simply because it is currently popular.

Ask:

> Will this still feel appropriate for NESTORA in three years?

If not, reconsider it.

# 75. Timeless Over Trendy

Prefer:

- Strong typography
- Good spacing
- Quality photography
- Clean navigation
- Clear product presentation

over temporary visual trends.

# 76. Realism Over Fantasy

The website should help customers imagine real furniture in real homes.

Avoid excessively surreal:

- AI landscapes
- Floating furniture
- Impossible architecture
- Unrealistic materials
- Fantasy environments

unless intentionally used for a specific campaign.

# 77. Materiality

Furniture is tactile.

Where appropriate, visual design can subtly reference:

- Wood
- Stone
- Linen
- Leather
- Metal
- Ceramic
- Natural fabrics

But do not literally decorate the UI with material textures everywhere.

The products themselves should communicate materiality.

# 78. Human Scale

Furniture is about living spaces.

Images and compositions should generally help users understand:

- Scale
- Proportion
- Context
- Comfort
- Placement

Lifestyle imagery is useful because it shows furniture in context.

# 79. Don't Oversell Luxury

NESTORA can feel premium without pretending to be an ultra-luxury furniture house.

The brand should remain approachable.

The customer should feel:

> "This is beautiful and well considered."

not:

> "This website is trying very hard to prove that this is luxury."

# 80. Brand Confidence

Confident design does not need to explain itself excessively.

Avoid unnecessary:

- Badges
- Labels
- Testimonials
- Statistics
- Claims
- Decorative messaging

Strong design can be quiet.

# 81. The "Remove 20%" Rule

When a page feels slightly overcrowded, attempt to remove approximately 20% of non-essential visual elements before adding anything else.

Ask:

> What can disappear without hurting the experience?

Often the answer improves the design

# 82. The "One Strong Idea" Rule

Each major section should have one dominant idea.

For example:

### Hero

**Introduce the brand.**

### Categories

**Help customers explore.**

### Best Sellers

**Show popular products.**

### Promotion

**Communicate a campaign.**

### Featured Products

**Showcase selected products.**

### Trust Stripe

**Reduce uncertainty.**

### Why Shop

**Explain the value.**

### Newsletter

**Build an ongoing relationship.**

If a section tries to accomplish five things simultaneously, simplify it.

# 83. The "One Primary CTA" Rule

A section should generally have one obvious primary action.

Secondary actions can exist, but they should not compete equally.

This prevents:

Shop Now

Explore

Learn More

View Collection

See Products

Get Started

Discover

all fighting for attention.

# 84. Visual Noise Test

Temporarily imagine the page without:

- Icons
- Borders
- Shadows
- Badges
- Decorative elements

If the underlying layout still works, the design is probably structurally strong.

Decoration should enhance the structure rather than rescue it.

# 85. The "Real Store" Test

Before approving a page, ask:

> If I replaced the fictional NESTORA products with real furniture inventory tomorrow, would this still feel like a credible store?

If yes, the design is likely on the right track.

# 86. The "Brand Memory" Test

After seeing the homepage, the customer should be able to remember:

- NESTORA
- Furniture
- A particular visual mood

They should not only remember:

> "That website with the cool animation."

Brand memory is more valuable than animation memory.

# 87. The "Five-Second" Test

Within approximately five seconds, a visitor should understand:

What is this?

Who is it for?

What can I do here?

For NESTORA:

> Furniture and home products for modern living.

with an obvious route into shopping.

# 88. The "No Explanation" Test

A good interface should not require a developer to explain how it works.

If the user needs instructions for:

- Finding products
- Opening the cart
- Adding to wishlist
- Checking out
- Viewing orders

the interaction probably needs improvement.

# 89. Final Taste Hierarchy

When making any design decision, use this order:

1\. Does it work?

↓

2\. Is it clear?

↓

3\. Is it useful?

↓

4\. Does it fit NESTORA?

↓

5\. Is it beautiful?

↓

6\. Is it delightful?

Do not reverse this hierarchy.

A beautiful interaction that does not work is not good design.

# 90. Final Creative Direction

NESTORA should feel like:

> **A modern furniture showroom translated into a digital experience.**

Not a dashboard.

Not a SaaS product.

Not an AI experiment.

Not a template.

Not a design exercise.

A real furniture brand.

The strongest expression of NESTORA is therefore:

**quiet confidence + beautiful products + thoughtful composition + effortless shopping.**

# 91. Final Rule

When in doubt:

> **Do less, but do it better.**

Use whitespace.

Use strong imagery.

Use typography deliberately.

Keep the interface calm.

Let the furniture speak.

Make every interaction feel intentional.

And never add something simply because an AI agent thinks the page "needs more."
